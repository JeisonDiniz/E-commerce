# Dependências do serviço web (API) em produção — subconjunto de
# requirements.txt SEM as libs de Machine Learning (pandas, numpy,
# scikit-learn, prophet, joblib).
#
# Por quê: essas libs só são usadas pelo pipeline de treinamento offline
# (app/ml/*, executado via `python -m app.ml.train`), nunca em request-time
# da API (os endpoints de predição só leem `ml_predictions` no Postgres —
# ver app/api/v1/endpoints/predictions.py). Prophet em particular compila o
# CmdStan no `pip install`, o que deixa o build da imagem Docker lento/pesado
# e é desnecessário para servir a API.
#
# Use este arquivo no Dockerfile do serviço web (Railway). Para rodar o
# treinamento (local ou em um job separado), continue usando
# requirements.txt, que inclui tudo daqui mais as libs de ML.
